# Fuentes para consultar

[Inicio](../README.md)

Consulta el contrato de las operaciones y la documentación correspondiente a JDK 21. Los ejemplos del curso son problemas propios para estudiar su secuencia.

| Área | Referencia |
|---|---|
| Lenguaje | [Dev.java: Learn Java](https://dev.java/learn/) |
| Java 21 | [Documentación de Java SE 21](https://docs.oracle.com/en/java/javase/21/) |
| Cadenas | [String](https://docs.oracle.com/en/java/javase/21/docs/api/java.base/java/lang/String.html) |
| Texto mutable | [StringBuilder](https://docs.oracle.com/en/java/javase/21/docs/api/java.base/java/lang/StringBuilder.html) |
| Arreglos | [Arrays](https://docs.oracle.com/en/java/javase/21/docs/api/java.base/java/util/Arrays.html) |
| Archivos | [Files](https://docs.oracle.com/en/java/javase/21/docs/api/java.base/java/nio/file/Files.html) |
| Datos binarios | [DataInputStream](https://docs.oracle.com/en/java/javase/21/docs/api/java.base/java/io/DataInputStream.html) y [DataOutputStream](https://docs.oracle.com/en/java/javase/21/docs/api/java.base/java/io/DataOutputStream.html) |
| Decimales | [BigDecimal](https://docs.oracle.com/en/java/javase/21/docs/api/java.base/java/math/BigDecimal.html) |
| Intervalos de tiempo | [System.nanoTime](https://docs.oracle.com/en/java/javase/21/docs/api/java.base/java/lang/System.html#nanoTime()) |
| Análisis de algoritmos | [Princeton: Analysis of Algorithms](https://algs4.cs.princeton.edu/14analysis/) |
| Benchmark de JVM | [OpenJDK JMH](https://openjdk.org/projects/code-tools/jmh/) |
| Instalación por sistema | [Eclipse Temurin](https://adoptium.net/installation/) |

Cuando consultes una API comprueba qué recibe, qué devuelve, si modifica el objeto y qué errores puede producir. Para estudiar complejidad, declara tamaño, operación contada y caso analizado antes de comparar cotas.
