# Glosario

[Inicio](../README.md)

| Término | Significado en el curso |
|---|---|
| Algoritmo | Secuencia precisa de pasos para resolver un problema bajo entradas y reglas |
| Programa | Implementación de un algoritmo en un lenguaje ejecutable |
| Contrato | Entradas admitidas, resultados y comportamiento ante incumplimiento |
| Variable | Nombre tipado que conserva un valor |
| Asignación | Evaluar una expresión y guardar su resultado |
| Contador | Variable que registra cantidad de eventos |
| Acumulador | Variable que reúne valores de un recorrido |
| Invariante | Propiedad que se conserva en un objeto o tras cada iteración |
| Vector | Arreglo unidimensional en este curso |
| Matriz | Estructura numérica con filas y columnas bajo una forma definida |
| Capacidad | Espacio reservado para elementos |
| Cantidad lógica | Elementos efectivamente utilizados |
| Clase | Definición de estado y comportamiento de un tipo de objeto |
| Objeto | Instancia con su propio estado |
| Constructor | Operación que inicializa una instancia válida |
| Registro | Agrupación de campos relacionados |
| Record de Java | Construcción del lenguaje con componentes, accesores e igualdad de valores |
| Persistencia | Conservación de información fuera de la memoria del proceso |
| Codificación | Regla para representar texto como bytes |
| Cota asintótica | Descripción de crecimiento bajo parámetros y modelo de costo declarados |
| Espacio auxiliar | Memoria adicional utilizada, según si el análisis incluye o excluye la salida |
| Hilera | Cadena o secuencia textual |
| Unidad UTF-16 | Unidad de16 bits usada por char y los índices de String |
| Punto de código | Valor de Unicode; no siempre equivale a un símbolo percibido completo |
| Centinela | Valor especial acordado para terminar un recorrido de entrada |
